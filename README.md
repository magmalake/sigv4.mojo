# sigv4.mojo

[![CI](https://github.com/magmalake/sigv4.mojo/actions/workflows/ci.yml/badge.svg)](https://github.com/magmalake/sigv4.mojo/actions/workflows/ci.yml)

Part of [**magmalake**](https://magmalake.org) — data lake building blocks in Mojo.

**AWS Signature Version 4** in pure [Mojo](https://www.modular.com/mojo): the
canonical request, string to sign, signing-key ladder, the `Authorization`
header, and presigned query strings. No FFI shim and no C library — the one
foreign call is libc's `time`.

It ships its own crypto, because SigV4 is built from exactly two primitives and
nothing on a conda channel provides them for Mojo:

- **SHA-256** (FIPS 180-4) with three compile-time backends: the ARMv8 SHA-2
  extension (every Apple Silicon and server aarch64 part), Intel/AMD SHA-NI,
  and a fully unrolled scalar fallback.
- **HMAC-SHA256** (RFC 2104).

Extracted from [objectstore.mojo](https://github.com/magmalake/objectstore.mojo),
where it signs S3 requests; [maws](https://github.com/magmalake/maws) uses it
for EC2, Cost Explorer and Pricing.

## Verified against

- every usable case of the published **`aws-sig-v4-test-suite`** (as vendored in
  awslabs/aws-c-auth) — canonical request, string to sign and signature, each
  asserted separately (`tests/sigv4_vectors.mojo`, generated by
  `tools/gen_sigv4_vectors.py`);
- FIPS 180-4 SHA-256 vectors, including the one-million-`a` message fed in
  awkward chunk sizes; hardware backend == scalar backend on random inputs;
  and OpenSSL's `libcrypto` as an oracle when the environment has it;
- RFC 4231 HMAC-SHA256 vectors.

## Use

```mojo
from sigv4.signer import AmzTime, Header, QueryParam, sign_request
from sigv4.crypto import sha256_hex

var body = String('{"Granularity":"MONTHLY"}')
var when = AmzTime.now()
var headers: List[Header] = [
    Header("host", "ce.us-east-1.amazonaws.com"),
    Header("x-amz-date", when.amz_date),
    Header("content-type", "application/x-amz-json-1.1"),
    Header("x-amz-target", "AWSInsightsIndexService.GetCostAndUsage"),
]
var signed = sign_request(
    "POST", "/", List[QueryParam](), headers, sha256_hex(body),
    access_key, secret_key, "us-east-1", "ce", when, normalize=True,
)
# send `signed.authorization` as the Authorization header
```

| module | what |
|---|---|
| `sigv4.signer` | `sign_request`, `presign_query`, `canonical_request` / `canonical_path` / `canonical_query` / `canonical_headers`, `string_to_sign`, `signing_key`, `AmzTime`, `Header`, `QueryParam`, `url_encode` |
| `sigv4.crypto` | `sha256`, `sha256_hex`, streaming `Sha256`, `hmac_sha256`, `to_hex` / `from_hex`, `sha256_backend()` |

`normalize=True` collapses `.`/`..` and duplicate slashes in the path, which is
what every AWS service except S3 wants; S3 signs the path as written.

Signing is all that is here: credentials, HTTP and retries are the caller's.
